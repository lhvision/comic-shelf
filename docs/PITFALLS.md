# 错题本与避坑红线（Pitfalls Ledger）

> 纸间核心避坑速查表。全仓重构、审查或提交前必须逐条核对，严禁踩踏红线。

---

1. **不要**在清理未引用 import 时删除被隐式依赖的全局变量或使用废弃别名；**必须**将权限标识统一收敛为 `is_curator`，改动后跑通 `pnpm test:py`（因误删 `auth.py` 的 `is_admin` 曾导致全站写操作报 500 NameError）。
2. **不要**假设所有原站响应均为合法漫画 HTML；**必须**前置探测 `album_missing` 错误页特征并抛出 404 友好提示（因下架本子重定向导致正则解析崩溃报 500）。
3. **不要**在增量追加图片时仅局部自增目标章节；**必须**全书重排 `rebuilt_pages` 保持 `ch.start` 与 `page.index` 从 1 严格单调递增（因局部自增曾导致全书页码断裂、阅读器翻页跳页）。
4. **不要**直接读取未经校验的本地路径或扫描系统根目录；**必须**通过 `_is_path_allowed()` 限制在 `ALLOWED_DIRS` 白名单沙箱内（防止任意文件扫描与宿主机目录遍历攻击）。
5. **不要**向模板传递未解构的 Composable 包装对象；**必须**在 `<script setup>` 顶层显式解构后绑定（因 Vue 3 仅对顶层变量自动 unwrap，嵌套 Ref 会渲染为 `[object Object]` 或丢失响应性）。
6. **不要**在阅读器内部翻页切话时触发全屏视图过渡；**改用**仅限跨页面路由跳转，且所有 `startViewTransition` 必须 catch 兜底（因全局快照排他，快速翻页被浏览器 Abort 抢占会导致白屏崩溃）。
7. **不要**在带有 Hover 浮动、叠牌旋转或柔和阴影的卡片上配置 `contain: paint` 或 `content-visibility: auto`；**改用** `contain: layout style` 并通过 48 图预算增量渲染（因 `contain: paint` 强制将超出边界的投影硬切出黑边）。
8. **不要**在 memoize 异步函数失败时残留缓存；**必须**在 catch 中调用 `.delete(key)` 清理，且包装函数必须显式声明完整参数签名（因被 Abort 的请求若保留 rejected 缓存会导致用户重试永久报 AbortError）。
9. **不要**在内存已有书架数据时切页无条件将 loading 设为 true；**改用** SWR 策略静默回源，仅在初次无数据或主动下拉刷新时展示骨架屏（因无条件 loading 会导致切页瞬间卡片消失闪现骨架屏）。
10. **不要**在组件调用时使用未在 Props 与 Composable 联合类型中定义的变体别名（如废弃的 `variant="solid"`）；**必须**保持 1:1 类型契约对齐并确保 `vp check` 零报错（防止静默样式丢失与类型腐化）。
11. **不要**在模板中书写 Unicode 伪图标文本（`✕`/`✓`/`×`/`⋯`/`←`）或手写散落内联 `<svg>`；**必须**统一使用 `src/components/icons/` 原子组件与 `AppIcon` 分发（因跨平台字体字重不一致导致基线撕裂、且读屏器会将 `×` 误读为乘号）。
12. **不要**在仓库任何代码、文档或配置中写入宿主机绝对路径（如 `file:///home/...` 或 `C:\Users\...`）；**必须**统一使用仓库相对路径，写盘前必须剥离 AI 对话的 `file://` 协议（因绝对路径在他人 clone 或部署到 NAS 时全部失效泄露）。

---

## 🚦 交付门禁（三步必跑）

1. **静态检查**：`vp check`（前端 0 error、0 warning、格式规范）；
2. **后端测试**：`pnpm test:py`（后端 0 syntax/import error，中间件全链路测试通过）；
3. **定向单测**：仅运行改动对应的单测文件（严禁无差别全量阻塞）。
