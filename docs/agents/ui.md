# UI 设计与开发指南（基于 Impeccable Skill）

> **核心原则**：本项目所有涉及 UI/UX 的设计、页面起草、组件重构、视觉打磨与响应式适配任务，**必须优先激活并调用 `impeccable` skill** 执行。

---

## 一、核心认知（铁律）

1. **Slop 不是画功问题，而是向平均审美回归**：
   AI 产出“模板感/廉价感”的根因是在没有明确约束时必然向训练数据的高频均值回归。换用更强模型只会提高回归的精致度，无法改变回归行为本身。
2. **解法：约束 + 流程逼出有辨识度的决策**：
   - 单纯黑名单（禁紫色渐变、禁毛玻璃）只能拦截显性元素，拦截不了套模板的隐性行为。
   - 必须通过 Impeccable 流程分离“方案决策”与“代码实现”。
3. **人是最终决策者**：AI 负责专业分析、提出多方向方案与精准执行；视觉基调与关键取舍必须由人类确认。
4. **迭代式协作**：严禁“一句 Prompt 吐出整个页面”。小步推进，一次只聚焦一两个点。

---

## 二、任务分级（防过度工程化）

在处理 UI 任务时，Agent 必须先根据任务粒度决定是否需要调用完整 Impeccable 流程：

- 🟢 **轻量级（单点修补/微调）**：
  - **场景**：修复已有样式的显性 bug、微调 padding/margin/shadow/containment、文字溢出截断、调整简单的 hover 态。
  - **处理方式**：直接读取现有设计文档与设计 Token 进行最小必要修改，运行 `vp check` 与对应的单一组件单测，**绝对禁止自行启动 E2E 浏览器测试**，**无需**空转完整的设计评审流程。
- 🔴 **重量级（新建页面/核心重构/视觉升级）**：
  - **场景**：新增功能视图、核心交互重构、组件体系演进、视觉风格翻新。
  - **处理方式**：**必须激活 `impeccable` skill**，严格按照 Impeccable 工作流分阶段推进。

---

## 三、Impeccable Skill 调度与执行指引

遇到重量级 UI 任务时，Agent 应主动查阅并调用 `impeccable` skill，按如下阶段推进：

| 阶段                | 任务目标                                          | 推荐使用的 Impeccable 命令 / Playbook                                |
| :------------------ | :------------------------------------------------ | :------------------------------------------------------------------- |
| **1. 规划与发现**   | 在写代码前理清功能边界与交互诉求                  | `shape [feature]` 或 `new-work`                                      |
| **2. 方案与基调**   | 提出 2~3 个视觉与布局方向供人类选择，拍板后才起稿 | Impeccable `craft-floor` / 视觉方向确认                              |
| **3. 评审与挑刺**   | 切换独立上下文，以设计总监视角审查代码与视觉缺陷  | `critique [target]`（主观打分）与 `audit [target]`（技术/a11y/性能） |
| **4. 系统打磨**     | 消除裸写数值，对齐设计系统与 Token 体系           | `polish [target]`                                                    |
| **5. 响应式与变体** | 处理多端断点适配或现场变体选择                    | `adapt [target]`（响应式）/ `live`（变体直选）                       |

---

## 四、项目特定约束

在执行 Impeccable 流程时，始终遵从当前项目的既有事实源：

1. **设计真相源**：改动前必读项目现有的设计决策文档（如 `DESIGN_NOTES.md`）与设计 Token（如 `src/styles/tokens.css`），不随意引入外部未经约定的样式库。
2. **业务底线**：UI 交互不得违背项目的核心业务规则（如本地优先、解密缓存流、分章作用域与全局页码映射等）。
