# ADR 0027 — 本地标识双轨分配（自填 / 路径推断 / 时钟）

- **日期**：2026-09-20
- **状态**：Accepted

本地自建的 `source_id` 不是禁漫车号，也不是「未填就一律时间戳」。馆长自填则规范化后采用，撞车 409；未填时，服务器路径导入用文件夹名或 PDF 文件名（纯数字如 `2899054` 仍合法，sanitize 成空串才退回时钟），网页上传与暂存 PDF 直接用 `YYYYMMDD_HHMMSS`。推断名与时钟撞车加 `_1` 后缀，同一路径再导入是另一本，不按来源路径去重。标题未填时用原始路径名，与 slug 不必相同。

这样磁盘目录对路径导入可读，上传仍有单调唯一键；`display_id` 的 `LOC_` 前缀已经把本地印章从禁漫数字车号里隔开。拒绝第三条静默规则（把数字名改写成时钟），也拒绝为去重去记「导入原点」。
