# ADR 0039 — PWA 多端阅读会话协同与冷启动轻量对齐

- **日期**：2026-11-09
- **状态**：Accepted
- **关联**：承接 ADR 0005 (PWA 离线存储)、ADR 0035 (PWA 会话恢复与案头时序置顶)

## 背景与问题

在 ADR 0035 中，纸间落地了 PWA 独立视口冷启动时「阅读会话恢复（Reading Session Resume）」能力。当读者在阅读器内直接划掉退出应用时，端侧将当前作品、页码与 `active = true` 暂存于本地 LocalStorage（`comic-shelf:active-reading-session:v1`），并在下次点击应用图标时秒级直达断点。

然而，在多设备（Cross-Device，如手机 PWA 与平板/PC 浏览器）混合阅览场景下，该机制暴露出时序割裂缺陷：

1. **单机本地记忆孤岛致使回到旧进度**：
   - 读者在设备 A（手机 PWA）读到第 10 页后直接划掉退出；
   - 随后在设备 B（平板/电脑）继续翻阅该漫画至第 45 页并退出（第 45 页已通过 `PUT /api/library/{source}/{source_id}/progress` 正常同步至服务端 SQLite）；
   - 当读者再次在设备 A 上冷启动打开 PWA 时，`LibraryView` 的 `tryResumeSession` 盲信设备 A 本地 LocalStorage，直接重定向至 `/read/10`，读者被迫回到旧进度；
   - 必须先在阅读器内点击顶栏返回回到书架（书架拉取到服务端真理源，显示第 45 页），再手动点进阅读器才能接续。
2. **完结状态无法跨端感知**：
   若读者在设备 B 上已经完全读完了整部作品，设备 A 的本地 LocalStorage 仍停留在 `active: true`，冷启动时仍会错误地直插旧页码，违背了“读完即归档、启动停留在书架”的预期。

## 核心决策

### 一、轻量服务端真理源对齐（Zero-Backend-Change SSOT Alignment）

摒弃过度工程化引入全局会话表或新接口的重型方案，直接复用既有的服务端进度接口 `GET /api/library/{source}/{source_id}/progress`：

1. **冷启动快速探针与网络层集成**：
   - 当设备冷启动检测到本地存在 `active = true` 的在读会话时，端侧已持有目标作品的 `source` 与 `source_id`；
   - 复用 HTTP 网络层内置的 `combineSignals` 基础设施，直接以 `api.getReadingProgress(s.source, s.sourceId, { timeoutMs: 600 })` 发起轻量探针，杜绝悬挂定时器句柄；
2. **时序、页码裁决与 TOCTOU 安全防线**：
   - **防御 TOCTOU 状态变异**：异步网络挂起期间，若读者发生账号注销、身份切换或会话被外部显式清空，兑现时主动放弃恢复，严防复活已失效的旧会话；
   - **404/401/403 幽灵会话清除**：若远端作品已被删除（404）或权限被收回（401/403），立即调用 `clearSession()` 物理级擦除本地残留，停留在书架，杜绝向已删除作品错误重定向；
   - **全书读完失活**：若 `total_pages > 0 && last_page >= total_pages`（已在其他端完全读完），统一收敛调用 `deactivateSession()` 失活本地会话，返回 `false`，应用停留在书架案头；
   - **最新进度接续**：若未完结，直接采用服务端最新的 `last_page` 作为恢复目标，同步刷新端侧 LocalStorage 中的 `page`、`totalPages` 与 `updatedAt`，直达最新画页；
3. **本地优先与毫秒级离线兜底**：
   - 若设备离线、网络异常或请求超过 600ms，`catch` 块平滑降级，直接使用设备本地 LocalStorage 记录恢复，坚守本地优先秒开底线。

### 二、严格场景边界（仅限冷启动恢复，常态场景零侵扰）

本次跨端自动对齐严格限制于 **PWA 冷启动未完结会话接续** 这单一场景：

- 读者在详情页点击「从头阅读」（第 1 页）时，严格尊重读者意图，视口锁定第 1 页；
- 读者在分话目录中主动点选特定章节页码、或通过台词检索气泡直达时，严格定位到指定物理页，绝对不触发跨端页码纠偏；
- 书架手边书与详情页「继续阅读」本就基于服务端最新进度流转，维持原状。

## 效果与收益

1. **消除多设备使用裂痕**：读者在手机和平板间随意换端阅读、直接划掉退出，下次打开均能 100% 精准接续最新阅读进度；
2. **零后端改动与零额外存储负担**：无需数据库迁移，复用既有微秒级 SQLite 查询接口；
3. **本地优先坚挺**：弱网与离线环境维持无缝秒开，杜绝阻塞白屏。
