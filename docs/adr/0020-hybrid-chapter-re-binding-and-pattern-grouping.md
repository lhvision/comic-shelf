# ADR 0020 — 远端漫画混合装订、章节智能切分与单话靶向重订架构

- **日期**：2026-09-14
- **状态**：Accepted

## 背景

纸间定位于“本地优先的个人漫画收藏夹”。在以往设计中，“增量追加（`append_pages`）”与“按章节装订”主要面向 `source = "local"` 的本地自建漫画。

然而在真实使用场景中，部分连载漫画因远端图源（如哔咔 PicAcg、JMComic）汉化停更、被封禁或断章，读者需要手动接续后续话数；或馆长在第三方渠道获取了比官方图源更高画质的全本资源（例如单目录平铺的 `1-1.avif`、`2-1.avif`），期望替换已有远端漫画。

原架构面临以下痛点：

1. **来源硬编码屏障**：`/api/library/local/{source_id}/append`、`AppendPagesModal` 与 `DetailActionBar` 严格锁定 `source === "local"`，远端漫画无法追加新章节或页面。
2. **单层复合文件名目录退化为平铺单卷**：许多第三方漫画源将全本所有画页放于同一文件夹下，采用 `1-1.avif`、`2-1.avif`（`<chapter>-<page>`）命名。原有装订逻辑仅以子目录区分章节，无子目录时强制降级为单卷平铺漫画，丢失所有章节结构与目录导航。
3. **单话重订副作用穿透与封面撕裂（Bug）**：原有 `replace_pages` 在替换单话（`target_chapter`）时，全量执行了 `shutil.rmtree(covers_dir)` 和 `shutil.rmtree(thumbs_dir)`，导致全本其他未改动章节的封面与缩略图被清空损坏。
4. **单话详情视口缺乏就地入口**：读者在 `ChapterView` 浏览某一话时，菜单仅有“删除本话”，无法就地重新装订当前话。

## 决策

1. **远端漫画混合装订与受控自管模型（Hybrid Remote Re-binding & Protection）**：
   - 彻底解除追加与上传接口对 `source = "local"` 的硬编码限制，统一泛化为 `/api/library/{source}/{source_id}/upload-pages` 与 `/append`。
   - 远端漫画一旦由馆长手动追加新章节或执行重新装订，系统自动在元数据中打上重新装订保护标记（`custom_pages: true`）。
   - **冻结远端全量重刷**：在受保护状态下，保留原始车号出处与基础元数据，但拦截远端覆盖式同步与图片重新拉取，确保本地手动补全的画卷作为单一真理源。

2. **复合画卷文件名智能正则切分与原标题继承（Pattern-based Auto-Grouping）**：
   - 扫描图片时，系统自动探测并提取复合章节前缀（支持 `^(\d+)[-_.#](\d+)`、`^(?:c|ch|ep|第)?(\d+)[-_话回卷期](\d+)` 等经典模式）。
   - 统一文件夹下同前缀图片聚类为一个独立 `Chapter`；按自然数字升序（`_natural_key`）稳定排序。
   - **原标题对齐与顺延命名**：全量装订时优先继承原有漫画各话的已有中文章节标题（如 `第1话：青梅竹马`）；对超出原话数的新增章节，以自然序号（`第 N 话`）顺延命名，单调重算 `Chapter.start` 与全局页码（1..N）。

3. **单话靶向装订与局部缓存失效（Targeted Scoped Invalidation）**：
   - 修复 `replace_pages`：单话重订时，仅删除与重建目标章节目录（`pages/<chap_id>`）与该章节内部缩略图；
   - 严禁清空全本 `covers_dir` 与 `thumbs_dir`，仅在目标章节恰好为全书首章时增量更新全书主封面（1..4 页）；
   - 单调重算目标章节之后所有章节的 `start` 偏移与全书总页数 `page_count`。

4. **双向全链路交互入口打通（Seamless UI Ergonomics）**：
   - **详情页（`ComicDetailView`）**：对所有可写漫画开放「增量追加…」入口；章节目录尾格提供轻量「+ 追加新话」快捷卡片；
   - **单话页（`ChapterView`）**：在顶栏更多选单中就地提供「重新装订本话…」与「在本话追加画页…」，开箱即用。

5. **现代多媒体原图无损与缩略图双模**：
   - 正文画页 100% 保持原始 `.avif` 二进制存储，Pillow 执行完整性探测；
   - 缩略图与封面增量转码为标准 WebP / JPEG，保障老旧设备全端秒开。

## 后果

- **正面收益**：
  - 完美解决停更连载漫画的手工接更痛点，既能整本替换高清 AVIF 并保留分话目录，又能平滑追加后续最新话；
  - 彻底修复单话装订损坏全本缩略图的历史遗留 Bug；
  - 保持纸间“本地优先、数据完整性第一”的核心价值观。
- **注意事项**：
  - 标记 `custom_pages: true` 的漫画不再受远端爬虫刷新影响；若馆长未来需要恢复纯远端同步，可在编辑资料中手动解除重新装订保护。
