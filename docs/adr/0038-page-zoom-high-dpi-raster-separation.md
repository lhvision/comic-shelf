# ADR 0038 — 画页放大动静分相高清栅格化架构

- **日期**：2026-11-08
- **状态**：Accepted
- **关联**：承接 ADR 0001 (阅读器全局状态)、ADR 0017 (台词气泡覆盖层)、ADR 0021 (现代 CSS 规范与设计系统 Token 治理)

## 背景与问题

纸间（Paper Room）定位于「本地优先的个人漫画收藏馆与私密阅览室」。在阅读器中，读者常通过双击（PC 端双击或移动端 320ms 内双触）画页放大 2.5 倍以浏览漫画细节与微小对白文字。

在此前的实现中，画页放大是通过对画页容器 `.page-frame` 施加 CSS 变换驱动的：

```css
transform: translate3d(panX, panY, 0) scale(2.5);
```

这一实现暴露出严重的视觉品质缺陷：

1. **GPU 纹理拉伸插值模糊**：
   在常规阅读排版下，浏览器根据视口尺寸（如 400px~800px 宽度）将 `<img>` 元素栅格化为一个标准 DPI 的 GPU 纹理图层。双击放大时，`scale(2.5)` 仅由 GPU 合成器对该已降采样的纹理进行双线性拉伸（Bilinear Texture Blit）。即使用户收录的画卷原图拥有 1600px~2500px 的超高清分辨率，浏览器合成器也未能从底层解码位图重新采样，导致对白字迹与线稿严重发虚变糊。
2. **与移动端原生双指缩放的巨大体验落差**：
   在手机浏览器中，用户双指捏合缩放（Pinch-to-zoom）操作的是视口（Visual Viewport）。浏览器引擎会直接调度物理屏幕像素从内存原始位图重新栅格化（Re-rasterization），展现 1:1 像素级的锐利画质。纸间阅读器的画页放大清晰度远远落后于手机原生视口缩放。

因此，亟需在不破坏 60fps/120fps 丝滑平移与条漫长卷性能的前提下，重构画页放大的渲染管线。

## 核心决策

### 一、动静分相栅格化（Render Scale Separation）

将「渲染分辨率提升」与「几何平移运动」解耦：

1. **物理渲染分辨率提升**：
   当画页被激活放大时，通过在单页沙箱内将图像实际渲染尺寸（Render Layout Dimension）提升为基准缩放倍率（`scale: 2.5`），强制浏览器按高分辨率物理像素重新栅格化 `<img>`，让解码器直接将画卷原图的丰富细节投射至渲染表面，实现 1:1 原画清晰度。
2. **GPU 硬件加速平移**：
   读者的拖拽平移、滚轮微调与键盘方向键平移，仍由 `transform: translate3d(panX, panY, 0)` 硬件加速接管。在平移漫游细节时，合成层零 Reflow 重排，稳定维持 60fps / 120fps 的物理平滑体验。

### 二、首帧超采样动效（Instant Supersampling）

在双击激活画页放大的瞬间，该页即刻完成高分辨率图层初始化，0.22 秒平滑过渡动效自第一帧起即由高清图层驱动几何变换（Supersampled Scaling）：

- 利用 `@keyframes zoom-supersampled-enter` 实现自 `scale(0.4)`（即 $1 / 2.5$，视觉尺寸与未放大前 100% 严丝合缝）平滑膨胀至 `scale(1)`；
- 动画全程与静止状态均保持晶莹剔透的高清采样；
- 杜绝“先拉大模糊纹理、动画完成后突然刷新变清晰”的两段式视觉割裂闪烁（Flash of Blur），并在 `@media (prefers-reduced-motion: reduce)` 下自动降级为静态瞬态对焦。

### 三、单页高清沙箱隔离（Single Page High-DPI Sandbox）

为杜绝超长篇条漫（`vertical-continuous`，单部作品常达数百页）在移动设备上的内存膨胀（OOM 风险）：

1. **单页生效与长宽比锁定**：高分辨率重栅格化严格仅对当前唯一处于激活放大态的画页（`zoomedPage === page`）生效；通过注入真实画格测量尺寸 `--zoomed-width: w * scale` 与 `--zoomed-height: h * scale`，彻底杜绝容器宽高比失衡引发的画格形变与气泡偏位；
2. **零文档流外溢与物理锁高**：画页的高清尺寸扩展局限于其内部隔离层，外层父容器与兄弟节点在主文档流中的几何尺寸保持不变，长卷条漫注入 `minHeight: measuredHeight` 锁定物理高度，防止瀑布流后续页面产生重排或滚动跳动；
3. **即时释放**：当读者点击悬浮胶囊、按 `Escape` 或再次双击执行还原视图（Reset Zoom）时，立即释放高分辨率图层，内存占用与布局瞬间复原。

### 四、气泡呼吸覆盖层与防脱轨几何等比映射

1. **台词对白气泡（`ReaderBubbleOverlay`）**：
   气泡呼吸高亮覆盖层基于百分比坐标定位，随高分辨率图层等比扩张，使检索命中的台词高亮线框与对白文字一同呈现高清锐利质感，几何坐标零偏位；
2. **防脱轨平移约束（Edge Clamping）**：
   严格根据放大后的有效画面物理范围实施动态截断（`clamp(pan, -maxPan, maxPan)`），确保放大状态下拖拽绝不露底或出现断裂黑边。

## 影响与收益

- **画质飞跃**：画页放大彻底告别 GPU 模糊插值，获得与手机原生视口缩放一致的 1:1 视网膜级清晰度；
- **架构极简**：基于浏览器原生渲染管线与 CSS 特性实现，零引入额外第三方重型图像缩放或 Canvas 切片库，严格遵守本地优先阅览室的轻量防劣约束；
- **全端统一**：PC 端鼠标双击与移动端 320ms 双触共享完全一致的高清对焦体验。
