# ADR 0008 — 访客防滥用防护：设备争抢置换熔断锁、令牌桶速率限流与隐私默认隐藏策略

- **日期**：2026-08-30
- **状态**：Accepted
- **关联**：承接并加固 ADR 0007（访客通行证设备插槽配额与 LRU 淘汰漫游架构）

## 背景

在 ADR 0007 落地了基于物理设备插槽与 LRU 滑动淘汰机制后，系统在“合法朋友多端自由漫游”上体验良好。但在零信任与对抗性边界分析中，暴露出以下威胁模型与系统脆弱性：

1. **恶性设备置换拒绝服务（DoS by LRU Thrashing）**：
   - LRU 淘汰遵循“后到者优先”置换原则。若恶意攻击者通过脚本以伪造的 User-Agent 每秒发起登录，合法号主的设备将在阅读时秒级收到 401 并频繁掉线，陷入“登录 → 被挤下线 → 再登录”的死循环；
2. **凭据泄露导致全站图片批量拖取（Bulk Scraping & Bandwidth Exhaustion）**：
   - 现有的 Hotlink 防盗链仅校验跨站外链引用（`Sec-Fetch-Site: cross-site` 与 `Referer`），无法阻断携带合法 Cookie / Token 的爬虫脚本并发调用 `/api/library/.../pages/{index}/file`；
   - 访客缺乏请求速率控制，多线程爬虫可拉满 NAS 上行带宽与 CPU 并发；
3. **全馆可见性下的私人敏感藏书误泄露（Private Collection Leakage）**：
   - 访客通行证默认为全馆通票，仅屏蔽 `hidden_from_guest: true` 的单本藏书。馆长新收录私人藏书时若疏忽未打标，访客即可在书架直接查阅。

## 决策

1. **设备置换频次熔断冷却锁（Eviction Cooling Lock）**：
   - 服务端在内存中维护每个 Pass 的设备置换时间戳滑动窗口（5 分钟 = 300 秒）；
   - 若单张通行证在 **5 分钟内连续置换新设备超过 3 次**，判定为恶意设备争抢，自动激活 **10 分钟置换冷却锁（Cooling Lock）**；
   - **锁定期间策略**：
     - 当前已登记在册的合法物理设备 100% 正常阅读，完全不受影响；
     - 任何企图新接入并置换旧端的新设备请求均被拦截，返回 HTTP `429 Too Many Requests`（“设备置换过于频繁，通行证已启动安全保护，请稍后再试”）；
     - 冷却期结束后若无新高频争抢，自动恢复正常 LRU 置换。
2. **轻量内存令牌桶速率限流（Guest Rate Limiting / Token Bucket）**：
   - 针对 `guest` 角色的静态页面/封面二进制请求（`.../file`, `.../thumbnail`, `.../cover`），在 FastAPI 中间件层挂载轻量级纯内存令牌桶：
     - **持续限额（Sustained Rate）**：`120 页 / 分钟`（相当于每秒可稳定拉取 2 张大图）；
     - **瞬时突发容量（Burst Capacity）**：`45 张`（覆盖读者打开画集时的瞬时预取及快速划屏寻页）；
   - **超额惩罚**：仅当超出速率且突发桶耗尽时，返回 HTTP `429 Too Many Requests`（“翻阅速率异常（超过 120 页/分钟），请稍憩数秒”）；
   - 纯 Python 内存管理（毫秒级算术运算），无外部 Redis 依赖。
3. **新入库藏书默认隐身策略（Default Hide for New Imports）**：
   - 在全局设置（`data/settings.json`）中提供 `guest_hide_new_comics: bool` 配置；
   - 在前端导入面板（`ImportPanel.vue`）提供轻量勾选框；
   - 开启后，任何通过远端收录或本地扫描新增的书籍，其元数据初始状态自动置为 `hidden_from_guest = True`，馆长核验并确认适合借阅后方在卡片底部主动公开，从根源规避疏漏事故。
4. **馆长态势感知与一键熔断（Curator Observability & Mitigation）**：
   - 当通行证处于冷却锁定或触发过限流时，馆长名册卡片呈现警示印章 `〔 ⚠️ 设备频繁争抢锁定中 〕` 与琥珀色告警提示；
   - 馆长在名册中点击「重置密钥」，可一键作废旧口令并强制清空所有关联设备，瞬间终止恶意连接。

## 后果

- **彻底瓦解自动化攻击**：5 分钟 > 3 次熔断锁直接阻断了暴力刷 UA 挤人的攻击脚本，保障了在看读者的持续连贯体验；
- **爬虫拖库秒级拦截**：120P/min + 45P 突发使多线程爬虫失效，同时 100% 容纳了人类极限翻页与预加载行为；
- **私人藏书天然隔离**：默认隐藏开关将数据安全性提升至“默认安全（Secure by Default）”；
- **零依赖与极简架构**：完全在既有 FastAPI 中间件与 Python 原生数据结构内完成，无第三方基础设施负担。
