# 纸间 · 浏览器一键收录扩展 (Paper Room Extension)

纸间（Paper Room）官方专属 Chrome 浏览器扩展。在禁漫天堂、哔咔漫画、拷贝漫画等站点浏览时，鼠标右键直接将漫画添加入库，告别手动复制车号与频繁切换窗口。

---

## 🌟 功能特性

- **双模右键收录**：
  - **在详情/阅读页**：右键页面任意空白处，自动根据当前 URL 提取本子车号收录入库。
  - **在列表/搜索页**：无需打开新标签页，直接在漫画卡片封面或标题链接上右键，立即收录。
- **支持三大图源**：
  - **禁漫天堂**：支持主站与全部官方镜像（`18comic.vip`, `18comic.ink`, `jmcomic-zzz.*`, `comic18j-ada.*` 等）。
  - **哔咔漫画**：支持 `picawang.com`, `manhuapica.com` 等网页分享镜像（自动提取 24 位 Hex 车号）。
  - **拷贝漫画**：支持 `mangacopy.com`, `copy4000.com` 等全系列镜像。
- **系统通知与直达**：
  - 收录成功或命中已在库时，自动弹出系统通知并附带图书标题；
  - 点击通知即可在新标签页直接打开纸间阅读详情页。
- **极简无打扰**：
  - 零复杂 Popup 弹窗，点击工具栏图标直接在新标签页打开纸间书架主站。
  - 纯原生 Manifest V3 标准，无庞大前端框架包袱，打包体积仅数十 KB。

## 🚀 安装步骤

1. **获取离线扩展包**：
   - 从 GitHub Releases 下载最新版 `paper-room-extension.zip` 并解压到本地文件夹；
   - 或在 `comic-shelf` 项目根目录下运行 `pnpm build:ext` 生成。
2. **加载到浏览器**：
   - 打开 Chrome / Edge / Brave 浏览器，在地址栏输入：
     `chrome://extensions/`
   - 打开右上角的 **「开发者模式 (Developer mode)」** 开关。
   - 点击左上角 **「加载已解压的扩展程序 (Load unpacked)」** 按钮。
   - 选择解压出来的 `extension/` 文件夹。
3. **配置纸间服务地址**：
   - 在浏览器右上角扩展栏中，找到「纸间 · 一键收录」图标。
   - 右键点击图标，选择 **「选项」**。
   - 确认 **纸间服务地址**（默认 `http://localhost:8000`；若为局域网 NAS 或远程云服务器请输入实际地址）。
   - 若纸间服务端 `.env` 设置了 `AUTH_SECRET` 访问口令，请填入 **馆长访问口令**；未设置请留空。
   - 点击 **「测试连接」**，提示成功后点击 **「保存配置」**。

## 📖 使用方法

1. 打开禁漫天堂、哔咔漫画或拷贝漫画；
2. 找到想收录的本子：
   - **列表/搜索页**：直接在封面或标题超链接上 **鼠标右键** -> 点击 **「收录至纸间」**；
   - **详情页/阅读页**：在网页空白处 **鼠标右键** -> 点击 **「收录至纸间」**；
3. 扩展将自动发起后台收录并弹出系统通知：
   - 若漫画已在书库中，提示「该漫画已在书库中」；
   - 若为新漫画，提示「收录成功，正在后台就绪」；
   - 点击通知卡片，直接跳转至纸间对应阅读页。
