# 纸间 · 浏览器一键收录扩展 (Paper Room Extension)

纸间（Paper Room）官方专属 Chrome 浏览器扩展。在禁漫天堂、哔咔漫画、拷贝漫画等站点浏览时，鼠标右键直接将漫画添加入库，告别手动复制车号与频繁切换窗口。

---

## 🌟 功能特性

- **双模右键收录**：
  - **在详情/阅读页**：右键页面任意空白处，自动根据当前 URL 提取本子车号收录入库（在禁漫单话阅读页自动轻量探测并自愈回溯至相册主页入库）。
  - **在列表/搜索页**：无需打开新标签页，直接在漫画卡片封面或标题链接上右键，立即收录。
- **支持三大图源**：
  - **禁漫天堂**：支持主站与全部官方镜像（`18comic.vip`, `18comic.ink`, `jmcomic-zzz.*`, `comic18j-ada.*` 等）。
  - **哔咔漫画**：支持 `picawang.com`, `manhuapica.com` 等网页分享镜像（自动提取 24 位 Hex 车号）。
  - **拷贝漫画**：支持 `mangacopy.com`, `copy4000.com` 等全系列镜像。
  - **换域与内网容灾**：支持选项页动态增补自定义镜像域名或 IPv4 测试地址，自动清洗规则并具备防崩溃降级。
- **通知推送与静默模式**：
  - 选项页支持一键开启或关闭系统通知；
  - 开启后收录完成弹出系统卡片，点击直达阅读；
  - 关闭后切换为静默模式，仅通过工具栏图标彩色短角标反馈状态，彻底避免系统拦截声音与通知中心堆积。
- **智能上下文直达与安全边界**：
  - **在漫画页面点击图标**：经域名白名单核验图源（严格排除纸间自身路由与无关网页），直接在新标签页打开纸间该本子详情页（`${serverUrl}/comic/{source}/{id}`），后台静默确保就绪入库；纯跳转交互下正常入库不弹窗、不闪烁「已在」或「✓」角标，若发生连接失败或认证异常依然保留轻量错误反馈；
  - **在其他网页点击图标**：直接打开纸间书架主站；
  - **右键外链白名单防护**：在图源页面右键超链接时自动校验目标域名，阻断误点页脚外链广告或第三方外链的假阳性收录；
  - 零复杂 Popup 弹窗，纯原生 Manifest V3 标准，打包体积仅约 60 KB。

## 🚀 安装步骤

[![Download Chrome Extension](https://img.shields.io/badge/📥_下载扩展离线包-paper--room--extension.zip-c74c35?style=for-the-badge&logo=googlechrome&logoColor=white)](https://github.com/lhvision/comic-shelf/releases/latest/download/paper-room-extension.zip)

1. **获取离线扩展包**：
   - **方式 A（点击下载）**：从 GitHub Releases 下载最新版 [**`paper-room-extension.zip`**](https://github.com/lhvision/comic-shelf/releases/latest/download/paper-room-extension.zip) 并解压到本地文件夹；
   - **方式 B（本地生成）**：在 `comic-shelf` 项目根目录下运行 `pnpm build:ext` 生成；
   - **方式 C（免打包）**：直接在浏览器加载本项目现成的 `extension/` 源码文件夹。
2. **加载到浏览器**：
   - 打开 Chrome / Edge / Brave 浏览器，在地址栏输入：
     `chrome://extensions/`
   - 打开右上角的 **「开发者模式 (Developer mode)」** 开关。
   - 点击左上角 **「加载已解压的扩展程序 (Load unpacked)」** 按钮。
   - 选择解压出来的 `extension/` 文件夹。
3. **配置纸间服务地址与图源分流**：
   - 在浏览器右上角扩展栏中，找到「纸间 · 一键收录」图标。
   - 右键点击图标，选择 **「选项」**。
   - 确认 **纸间服务地址**（默认 `http://localhost:8000`；若为局域网 NAS 或远程云服务器请输入实际地址）。
   - 若纸间服务端 `.env` 设置了 `AUTH_SECRET` 访问口令，请填入 **馆长访问口令**；未设置请留空。
   - 查看或管理 **图源分流域名**：可展开「系统内置分流」抽屉查看三大图源 11 个官方发布页正规域名；遇到新分流镜像可直接输入添加（支持逗号/换行批量粘贴录入）或移除单个胶囊。
   - 点击 **「测试连接」**，验证权限无误后点击 **「保存配置」**（支持 <kbd>Ctrl+S</kbd> / <kbd>⌘S</kbd> 快捷保存）。

## 📖 使用方法

1. 打开禁漫天堂、哔咔漫画或拷贝漫画；
2. 找到想收录的本子：
   - **列表/搜索页**：直接在封面或标题超链接上 **鼠标右键** -> 点击 **「收录至纸间」**；
   - **详情页/阅读页**：在网页空白处 **鼠标右键** -> 点击 **「收录至纸间」**（若处于单话阅读页，扩展将自动探测相册并收录；若探测失败会提示前往相册主页空白处收录）；
3. 扩展将自动发起后台收录并弹出系统通知：
   - 若漫画已在书库中，提示「该漫画已在书库中」；
   - 若为新漫画，提示「收录成功，正在后台就绪」；
   - 点击通知卡片，直接跳转至纸间对应阅读页。
