# 纸间 · Paper Room — 手动替换页面组件（ReplacePagesModal）A 轨独立设计评审报告

**评审对象**：`src/components/detail/ReplacePagesModal.vue`（配合 `DetailActionBar.vue` 与 `tokens.css`）  
**评审角色**：独立设计总监（Design Director · Assessment A）  
**评审标准**：Nielsen 10 项可用性启发式准则、纸间典藏物理装订美学（Quiet Archive / Vermilion Ink）、WAI-ARIA 无障碍规范与认知负荷模型

| 1        | **系统状态可见性** (Visibility of System Status)       |   **2**    | 大文件异步上传期间仅有按钮微型 loading，缺失真实传输进度与分阶段反馈；待上传仅显示首尾文件名，缺失页数增减对比与文件体积统计                              |

### 2. Priority Issues（P0/P1/P2 缺陷清单）

1. **🔴 [P1] 假想 CSS Token 污染与暗色模式失效**：彻底替换 7 个不存在的 Tailwind/假想变量，严密绑定 `tokens.css` 原生语义（`--ink-0`, `--ink-1`, `--ink-2`, `--line`, `--radius-1`, `--radius-2`, `--duration-1`）。
2. **🔴 [P1] Dropzone 键盘焦点失联与 a11y 阻断**：为 Dropzone 赋予 `role="button"`、`tabindex="0"`、`aria-label` 与 Enter/Space 键盘触发，并在拖拽悬停时设置 `aria-dropeffect="copy"`。
3. **🔴 [P1] 盲盒式黑盒覆盖与去重缺失**：Stage 逻辑加入按文件名去重；在界面上呈现清晰明确的“现有 X 页 ➔ 选定 Y 页（增减比对）”物理计数牌，首尾文件名增加省略截断保护。
4. **🟡 [P2] 破坏性操作确认防线与警示态**：全量重置整本作品时追加高危销毁警示徽章，强化确认卡片质感。
5. **🟡 [P2] 上传中全表单状态锁定**：在 `submitting` 激活时对所有输入项、Dropzone 及选择控件加锁，防止中途破坏性误触。
6. **🟡 [P2] 移动端触控尺寸保底**：将 `.replace-ack` 勾选触控区扩大至 ≥44px 高度，断点收敛至全站标准（681px / 480px）。
