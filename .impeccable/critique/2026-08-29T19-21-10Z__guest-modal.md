# 纸间 · Paper Room — 访客簿模态框组件（GuestModal）A 轨独立设计评审报告

**评审对象**：`src/components/curator/GuestModal.vue`（集成 `Modal.vue`、`SegmentedTabs.vue`、`useGuestPasses.ts`）  
**评审角色**：独立设计总监（Design Director · Assessment A）  
**评审标准**：Nielsen 10 项可用性启发式准则、纸间典藏实体质感（Quiet Archive / Vermilion Seal）、WAI-ARIA 无障碍规范、单源滚动心流与触控工效

### 2. Priority Issues（P0/P1/P2 缺陷清单）

1. **🔴 [P1] 双重滚动陷阱与硬编码高度（Nested Scroll-Jacking & 420px Overflow Trap）**：
   - 现象：`.pass-card-list` 内部 `max-height: 420px; overflow-y: auto;` 与 `Modal.vue` 内部 `overflow-y: auto;` 产生双层嵌套滚动死锁，小屏手势容易卡死；
   - 修复：彻底剔除 `.pass-card-list` 的 `max-height` 与 `overflow`，名册卡片在 `Modal.vue` 现成的平滑单源滚动画卷中自然流动。
2. **🔴 [P1] 触控人机工效与移动端折行挤压（Sub-44px Touch Targets & Mobile Collision）**：
   - 现象：底栏按钮仅 32~36px，全量跌破 WCAG 2.5.5 与 Craft Floor 44px 底线，且展开确认时底栏剧烈横向拉伸折断；
   - 修复：增补 `@media (max-width: 640px)` 断点，所有触控目标拉升至 ≥40~44px，移动端将有效期与管理工具分两行编排。
3. **🔴 [P1] 印发流认知阻断与状态孤岛（Context Displacement on Issuance）**：
   - 现象：登记印发成功后粗暴切回名册，打断用户立即复制链接发给朋友的直觉心流，也阻碍连续派发；
   - 修复：印发成功后不切页，原位升格为「印发成功凭据卡（Issued Voucher）」，提供大号直达链接与「一键复制链接并发送」主按钮，下方提供「继续登记下一张」与「查看现存名册」双通道。
4. **⚠️ [P2] 异步状态防重入与剪贴板容错（Race Conditions & Clipboard Fallback）**：
   - 现象：连击操作缺少锁，非 HTTPS 局域网环境复制可能抛出异常；
   - 修复：引入 `operatingId` 防重入守卫；对 `copyShareLink` / `copyToken` 补充异常捕获与降级。
5. **⚠️ [P2] WAI-ARIA 选项卡语义与设计系统 Token 收敛**：
   - 补齐 `<section role="tabpanel">` 与 `aria-label`；
   - 消除硬编码 `#fff` 与 `rgba(0,0,0,0.04)`，全面采用 `--paper-0` 与 `--shadow-1`。
